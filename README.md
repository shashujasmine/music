Groovehub - Music Streaming Website

groovehub is a modern , spotify-inspired music streaming website built using pure HTML,CSS and JavaScript. It's frontend-only project , so there's no backend setup required-just open and play the music.

NOTE:
"I used AI for code debugging and project completion."

About:
This project focuses on creating a smooth and interative music player experience with a clean dark UI . it's designed to feel like a real music app while keeping everything simple and lightweight.

Features:

*Design:
Dark theme inspired by spotify.
Clean and minimal UI with smooth animations .
Fully responsive (mobile , tablet , desktop).
Modern layout with cards and soft shadows.

*Music player:
Play/Pause/Next/Previous
Shuffle and repeat
Progress bar with seek support
Volume control
Displays current time and duration 

*Search and Library:
Real-time search(song , artist,genre).
Browse playlists and recommendations
Like / unlike songs
view liked songs in library

*Tech Stack:
html5
Css3(Flexbox + grid)
JavaScript

*Getting Started 

1.Download or clone the project.
2.Open index.html in your browser.
3.Start playing music 

Data & Storage:

Songs and playing are stored in JavaScript.
Liked songs are saved in localStorage.
No data is sent to any server.

*Note:
"This is a frontend-only project.
1.No backend.
2.No database.
3.Contact or data is not stored externally.
